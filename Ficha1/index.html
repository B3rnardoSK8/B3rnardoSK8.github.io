Glossário


  • HTML (Hyper Text Markup Language)
    Linguagem de marcação utilizada para estruturar conteúdo na web.

  • CSS (Cascading Style Sheets)
    Folhas de estilo em cascata, usadas para estilizar páginas web.

  • JavaScript
    Linguagem de programação que permite criar conteúdo interativo na web.

  • C++
    Linguagem de programação de propósito geral, conhecida pela sua eficiência e desempenho.

  • C#
    Linguagem de programação desenvolvida pela Microsoft, amplamente utilizada para desenvolvimento de aplicações Windows e jogos.
